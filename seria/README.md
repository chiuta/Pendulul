# Aparatul de lume

Materiale de lucru ale seriei, păstrate pentru cine vrea să înțeleagă cum se leagă cifrele și faptele între volume. **Conțin spoilere.**

- [`canon.md`](canon.md): cifre și reguli obligatorii ale lumii (perioade, Fereastră, rachete, fire, cronologie).
- [`atlas.md`](atlas.md): geografia: locuri, nume locale, distanțe.
- [`cronologie-glosar.md`](cronologie-glosar.md): cronologia celor 20 de pendule și glosarul.
- [`aparat/`](aparat/): notele autorului, scoase din ediția cititorului (faptele introduse în fiecare volum).

Convenții din aceste fișiere: **[CANON]** = dat direct de canon; **[CALCUL]** = dedus aritmetic; **[PROPUS]** = completare propusă. Codurile „CANON2 C-nn” și „DECIZII” trimit la note de lucru intermediare care nu sunt incluse; textul volumelor din `carte/` este cel care contează.
